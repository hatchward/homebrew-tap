# Influpert Homebrew Tap

Homebrew formulae for [Influpert](https://influpert.com)'s tools, on macOS and Linux.

## Install

```sh
brew tap influpert/tap
brew install hatchward
```

Or in one step, without tapping first:

```sh
brew install influpert/tap/hatchward
```

## What's in the tap

| Formula | Description | Platforms |
| --- | --- | --- |
| `hatchward` | Multi-instance agent-fleet orchestrator — [hatchward.dev](https://hatchward.dev) | macOS, Linux |

`brew info influpert/tap/hatchward` shows the version currently offered.

## Supported platforms

- **macOS** — Apple Silicon (arm64) and Intel (x86_64)
- **Linux** — arm64 and x86_64

Formulae here ship prebuilt binaries, so there is no compile step and no bottles to
download. On Linux, Homebrew installs `git` as a dependency; on macOS the system
`git` is used instead.

## Verifying releases

Homebrew already checks the SHA-256 of the tarball it downloads against the checksum
pinned in the formula, so a normal `brew install` is verified. The steps below are for
checking the release manifest independently — for example before installing on a machine
you don't control, or to confirm a tarball you downloaded by hand.

Each release publishes a `SHA256SUMS` manifest, an Ed25519 signature over it, and the
public key:

```sh
VERSION=v0.3.1
BASE=https://github.com/influpert/homebrew-tap/releases/download/$VERSION

curl -sSLO $BASE/SHA256SUMS
curl -sSLO $BASE/SHA256SUMS.sig
curl -sSLO $BASE/hatchward-release.pem

# Verify the manifest signature
openssl pkeyutl -verify -pubin -inkey hatchward-release.pem \
  -rawin -in SHA256SUMS -sigfile SHA256SUMS.sig
# -> Signature Verified Successfully

# Verify a tarball you downloaded against the manifest
grep hatchward_v0.3.1_darwin_arm64.tar.gz SHA256SUMS | shasum -a 256 -c
# -> hatchward_v0.3.1_darwin_arm64.tar.gz: OK
```

On Linux, substitute `sha256sum -c` for `shasum -a 256 -c`.

`SHA256SUMS.sig` is a raw 64-byte Ed25519 signature, not a PGP signature — which is why
`openssl pkeyutl -rawin` is the right tool here and `gpg --verify` will not work on it.

Binaries are built and signed upstream, then mirrored onto this repository's releases so
the formula has a stable, publicly fetchable URL.

## Upgrading

```sh
brew update && brew upgrade hatchward
```

`brew update` is the step that pulls new formula revisions into your local copy of the
tap — `brew upgrade` alone will not see a new release.

## Uninstalling

```sh
brew uninstall hatchward
brew untap influpert/tap   # optional, removes the tap itself
```

## Troubleshooting

**`Error: No available formula with the name "hatchward"`**
The tap isn't installed, or your local copy is stale:

```sh
brew tap influpert/tap && brew update
```

**Checksum mismatch during install**
Your local tap clone is out of date relative to the published release. Run `brew update`
and retry. If it still fails afterwards, that's a packaging bug — please open an issue.

**Checking what actually got installed**

```sh
brew info hatchward
hatchward --version
brew test hatchward     # runs the formula's own version assertion
```

## Contributing

Formula files in this repository are generated by the hatchward release pipeline and are
rewritten on every release. Pull requests that hand-edit `Formula/*.rb` will be
overwritten by the next release and cannot be merged.

- **Packaging problems** — install failures, a missing platform, a wrong architecture, a
  bad checksum — are in scope for this repository. Please open an issue here.
- **Bugs in the tool itself** belong upstream. See [hatchward.dev](https://hatchward.dev).

## License

This repository holds packaging metadata. The tools it installs carry their own licenses.

`hatchward` is proprietary software distributed under its own EULA, which is installed
alongside the binary:

```sh
cat "$(brew --prefix hatchward)/share/doc/hatchward/LICENSE"
```

The formula declares `license :cannot_represent` because that EULA has no SPDX
identifier, so `brew info` will not display a license name for it.
